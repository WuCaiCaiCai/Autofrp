给 Docker 里的 NPM 使用

1. 在证书操作里点「导出 PEM」，复制 fullchain 与 privkey 内容。

2. 打开 NPM → SSL Certificates → Add Certificate → Custom Certificate，粘贴后保存，并在站点里选择该证书。

3. 续期后需要重新粘贴一次（NPM 的证书存在自己的数据库里，无法直接被文件替换）；面板会在证书临期时提示。

本工具不会修改 NPM 的数据库、容器或 compose 文件。
